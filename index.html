Folder access and browser backup help

Folder autosave needs a supported browser (currently Chrome or Edge) and localhost or HTTPS. If this app runs in a browser without folder picking, you can still edit, import and download JSON backups. Without a connected folder, edits stay in this tab only; download a new backup after making more changes. Leaving with edits prompts a warning. HTTPS alone cannot add a folder picker API that a browser does not support. Reconnect if permission expires. Profiles label files, not protect them. Anyone with folder access can read them. No team sync.

Backups include workspace projects, modules, reports, scenarios, test cases, screenshots and attribution. They are recovery copies, not folder autosaves.
